# Project Summary

Built a full-stack clinic appointment system (React/TypeScript frontend, Node/Express/Prisma backend, SQLite) supporting three roles — patient, doctor, and admin — with self-service booking, doctor schedule management, and clinic administration. The main engineering challenge was scheduling correctness: generating valid bookable time slots on demand from a doctor's recurring weekly hours, one-off exceptions, and clinic holidays, while guaranteeing — at the database level, not just in application code — that a doctor can never be double-booked, even when two booking requests arrive at the exact same instant.

- Designed a pure, framework-free slot-generation engine (no DB or HTTP dependencies) that composes weekly schedules, day-off/extra-hours exceptions, and clinic holidays into bookable slots, with a full unit test suite covering every edge case (breaks, exceptions, holidays, minimum notice, booking window, partial-fit slots).
- Prevented double-booking with a database-level uniqueness constraint (a generated `doctorId+startAt` key, nulled once an appointment leaves the active state) rather than relying on check-then-insert application logic, and proved it under a real race condition with a concurrency integration test firing two simultaneous booking requests.
- Modeled the appointment lifecycle as an explicit state machine with role- and time-gated transitions (e.g., only a doctor/admin can mark a visit completed, and only after it starts) and a full audit trail (`appointment_events`), returning consistent `409` errors on invalid transitions.
- Enforced authorization server-side in every layer — patients, doctors, and admins each see and act on only what their role permits — verified with dedicated cross-role authorization tests, not just UI-level hiding.
- Built a layered backend (routes → services → repositories, with business rules isolated in pure `core/` modules) and a typed React frontend with role-aware routing, loading/empty/error states on every data view, and a CI pipeline that lints, typechecks, and runs all 56 tests on every push.
